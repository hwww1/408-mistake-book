# 408 错题收集器

在浏览器中读取 GitHub 私有仓库或本机的 408 分节练习册，自动识别每页题目，点击题目右侧按钮即可保存为可搜索、可复习、可打印的错题本。

## 隐私

- PDF 保存在私有仓库中，网页只使用用户提供的只读令牌读取。
- 令牌仅保存在当前浏览器标签页的 `sessionStorage`，不会写入代码仓库。
- 每道识别出的题目都有“＋错题”按钮，点击后自动裁出题目图片。
- 加入前可选择错误原因并填写笔记，确认后再保存。
- 在“我的错题”中点击题目图片可放大查看，并可随时修改错误原因或追加笔记。
- 在 Codex 内置浏览器中通过 Site tools 读取当前错题，不需要 OpenAI API 密钥。
- 未识别出的特殊排版页面仍可拖动框选，作为备用方式。
- 错题图片、错因和笔记默认保存在当前浏览器。
- 跨电脑时可用“导出备份”和“导入备份”转移错题数据。

## 使用

1. 打开网站，点击“连接私有 PDF 仓库”。
2. 创建仅允许读取 `408-pdf-library` 的 fine-grained token，并粘贴到网页。
3. 选择科目与小节，点击每道题右侧的“＋错题”，补充错误原因和笔记后确认。
4. 在“我的错题”中按科目、章节、小节、页码或题目搜索；点击题目可放大和继续编辑。
5. 标记掌握状态，也可以打印或导出备份。

## 询问 Codex（无需 API）

1. 在 Codex 桌面应用的内置浏览器中打开网站。
2. 进入“我的错题”，点开一道题，再点“问 Codex”。
3. 回到旁边的 Codex 对话，粘贴已复制的问题，或直接说“帮我分析当前错题”。
4. Codex 可读取当前题目的章节、错因和笔记，并在网页中查看放大的题目图片；也可把简短结论追加回错题笔记。

网站会把已打开的章节 PDF 完整保留在当前标签页内存中。加载完成后不会因为远程连接久置而消失，切换章节也不会再刷新整个页面。

也可以选择本机“按章节整理”文件夹，或直接多选 PDF，作为不连接 GitHub 时的备用方式。

建议使用最新版 Microsoft Edge 或 Google Chrome。
