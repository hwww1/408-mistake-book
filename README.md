# 408 错题收集器

在浏览器中读取 GitHub 私有仓库或本机的 408 分节练习册，自动识别每页题目，点击题目右侧按钮即可保存为可搜索、可复习、可打印的错题本。

## 隐私

- PDF 保存在私有仓库中，网页只使用用户提供的只读令牌读取。
- 令牌仅保存在当前浏览器标签页的 `sessionStorage`，不会写入代码仓库。
- 每道识别出的题目都有“＋错题”按钮，点击后自动裁出题目图片。
- 未识别出的特殊排版页面仍可拖动框选，作为备用方式。
- 错题图片、错因和笔记默认保存在当前浏览器。
- 跨电脑时可用“导出备份”和“导入备份”转移错题数据。

## 使用

1. 打开网站，点击“连接私有 PDF 仓库”。
2. 创建仅允许读取 `408-pdf-library` 的 fine-grained token，并粘贴到网页。
3. 选择科目与小节，点击每道题右侧的“＋错题”。
4. 在“我的错题”中按科目、章节、小节、页码或题目搜索。
5. 标记掌握状态，也可以打印或导出备份。

也可以选择本机“按章节整理”文件夹，或直接多选 PDF，作为不连接 GitHub 时的备用方式。

建议使用最新版 Microsoft Edge 或 Google Chrome。
